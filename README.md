# 手描きでスタンプメーカー (LINE Stamp Maker with Gemini AI)

名古屋芸術大学 オープンキャンパス 2026.7.24 ワークショップ用Webアプリケーション  
手描きのイラストや線画をもとに、Google Gemini API を活用してオリジナルのLINEスタンプパッケージおよび公式A4印刷フォーマットPDFを全自動生成します。

---

## 動作モード

本アプリは **アクセス元のホスト名** によって自動的に動作モードが切り替わります。

| | オンライン版 (本番デプロイ) | ローカル版 (開発用) |
|---|---|---|
| **判定条件** | `localhost` / `127.0.0.1` / `0.0.0.0` 以外 | `localhost` / `127.0.0.1` / `0.0.0.0` |
| **ログイン** | Google OAuth (nua.ac.jp ドメイン限定) | 不要 — ログイン画面をスキップ |
| **スタミナ制限** | あり (1時間1回復・最大50) | なし — 無制限 |
| **プロジェクト保存** | Supabase DB に自動保存 | なし — ブラウザのメモリ上のみ (リロードで消失) |
| **画像生成 (Gemini API)** | Edge Function 経由 (APIキーはサーバー側で管理) | `.env` に記述した APIキーでブラウザから直接呼び出し |
| **管理者判定** | `d-mukai@nua.ac.jp` のみ | 常に管理者扱い |
| **ログアウトボタン** | 表示 | 非表示 |

## 主な機能とワークフロー

### Step 1: 線画を描く
- **全画面キャンバス**: ペン / 消しゴム、線の太さ調整、Undo、一括クリア、位置移動。タッチ操作対応。
- **カメラ撮影 & 画像アップロード**: 手描きの紙をカメラで撮影、またはローカル画像をアップロード。
- **クロマキー透過処理**: 生成画像の背景色 (#FF00FF) を自動検出しアルファ透過。キャラクター内部の色は保護。

### Step 2: 画風とキャラクター設定
- **8種類のプリセット画風 + オリジナル**: コピック風、アニメセル画風、水彩画風、クレイ風、レトロポップ風、色鉛筆風、3Dフィギュア風、ピカソ風。
- **線画維持率スライダー**: 手描き線の特徴を残す割合を 20%〜100% で調整。
- **キャラクター詳細設定**: 自由記述でキャラクターの特徴を指定。
- **操作モード**: やさしいモード (ひらがな表記) / 通常モード / エキスパートモード (全文プロンプト自由記述)。

### Step 3: スタンプ作成
- **プロンプトキーワード選択**: 文字・感情・行動・状況・行事・飾りのカテゴリ別キーワードをワンタップ選択。
- **単体生成 / 一括生成**: 1枚ずつ、または最大8個を連続自動生成。
- **プレビュー**: 透過 / LINE風背景 / ダーク / 白 の4パターンで確認。ドラッグ並び替え対応。

### Step 4: メイン・タブ画像作成
- メイン画像 (240×240px) とトークルームタブ画像 (96×74px) を AI 自動生成。
- 個別にプロンプトを修正して再生成可能。

### Step 5: 保存 & PDF印刷
- 名古屋芸術大学オープンキャンパス公式 A4 テンプレート PDF へ画像を自動合成。
- アプリ内 PDF ビューアでレイアウト確認、ダウンロード、直接印刷。

## 技術スタック

- **フロントエンド**: React 19 / TypeScript / Vite / Tailwind CSS v4
- **バックエンド**: Supabase (認証・DB・Edge Functions)
- **AI 画像生成**: Google Gemini API (`gemini-3.1-flash-image`, `gemini-3.1-flash-lite-image`)
- **PDF生成**: pdf-lib
- **QRコード**: qrcode / react-qr-code
- **アイコン**: Lucide Icons

## ローカル開発環境のセットアップ

### 1. 依存パッケージのインストール

```bash
npm install
```

### 2. 環境変数の設定

プロジェクトルートの `.env` ファイルに Gemini API キーを記入します。

```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
```

> `VITE_SUPABASE_URL` と `VITE_SUPABASE_ANON_KEY` は本番用です。ローカル版では DB・認証を使わないため、未設定でも動作します。

### 3. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173` にアクセスします。  
ログインなし・スタミナなし・DB保存なしで、すぐにアプリを操作できます。  
APIキーが設定されていれば画像生成もそのまま動作します。

### 4. ビルド

```bash
npm run build
```

`dist/` フォルダに本番用ファイルが出力されます。

## オンライン版 (本番デプロイ) について

本番環境では以下が有効になります。

- **Google OAuth 認証**: `nua.ac.jp` ドメインのアカウントのみアクセス可能。
- **Supabase DB**: プロジェクト・スタンプ画像がクラウドに自動保存されます。
- **スタミナ制限**: ユーザーごとに最大50、1時間に1回復。管理者 (`d-mukai@nua.ac.jp`) は無制限。
- **Edge Function 経由の画像生成**: Gemini API キーはサーバー側シークレットとして管理。クライアントには露出しません。

デプロイ先の Supabase プロジェクトに以下のシークレットが必要です。
- `GEMINI_API_KEY`: Gemini API キー (Edge Function 用)
