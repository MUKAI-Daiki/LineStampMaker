# 手描きでスタンプメーカー (LINE Stamp Maker with Gemini AI)

名古屋芸術大学 オープンキャンパス 2026.7.24 ワークショップ用Webアプリケーション  
手描きのイラストや線画をもとに、Google Gemini API を活用してオリジナルのLINEスタンプパッケージおよび公式A4印刷フォーマットPDFを全自動生成します。

---

## 🚀 主な機能とワークフロー

### **Step 1: 線画を描く (Drawing & Capture)**
- **全画面最大化キャンバス ＆ サイドバーツール**:
  - ペン / 消しゴム ツール、線の太さ調整、Undo（元に戻す）、一括クリア機能、位置移動機能。
  - タッチ操作時の長押しメニュー抑制対応によりスムーズに指やペンで描画可能。
  - **自動保存・復元**: 描画した線画はローカルストレージへ自動保存され、リロード時も保持されます。
- **カメラ撮影 ＆ 画像アップロード**:
  - Webカメラからのリアルタイム撮影機能。
  - 手描きの紙をカメラにかざして撮影、またはローカル画像のアップロードに対応。
- **クロマキーマゼンタ（#FF00FF）透過処理**:
  - Gemini APIで生成された背景色（どぎつい紫色 #FF00FF）を自動検出しアルファ透過。キャラクター内部の白や淡い塗り（水彩風など）は100%保護。

---

### **Step 2: 画風とキャラクター設定 (Style & Character Setup)**
- **多彩なプリセット画風 (8種類 + オリジナル)**:
  - コピック風、アニメセル画風、水彩画風、クレイ（粘土）風、レトロポップ風、色鉛筆風、3Dフィギュア風、ピカソ風、オリジナル（線画活かし）。
- **線画維持率調整 (20% 〜 100%)**:
  - スライダーで手描き線の特徴を残す割合を調整。
- **キャラクター詳細設定**:
  - キャラクターの特徴（例: 「青い髪の男の子」「柴犬のキャラクター」）を自由記述。
- **操作モード切り替え**:
  - **やさしいモード**: 小さなお子様向けのひらがな表記モード。
  - **通常モード**: 標準的な操作と詳細設定を表示。
  - **エキスパートモード・デバッグモード**: 全文プロンプト自由記述やモデル選択に対応。

---

### **Step 3: スタンプ作成 (Stamp Variation Generator)**
- **プロンプトキーワード選択タグ**:
  - 文字・感情(喜)・感情(悲/怒)・行動・状況・行事・飾りのカテゴリ別キーワード（「おはよう」「ありがとう」「おやすみ」等）をワンタップ選択。
  - 指定文字 (`*`) によるカスタムテキスト挿入。
- **生成モード**:
  - **単体生成**: プロンプトを選択して1枚ずつ作成。生成後のプレビュー表示中も止まらず連続生成が可能。
  - **一括生成モード**: 最大8個のプロンプトを選択し、ワンクリックで全バリエーションを連続自動作成。
- **Gemini API 連携 ＆ 自動リトライ**:
  - `gemini-3.1-flash-image` を使用した高品質画像生成。
  - タイムアウト・レート制限時の自動リトライロジックを搭載。
- **スタンププレビュー ＆ タッチ/ドラッグ操作**:
  - 透過 / LINE風背景 / ダーク / 白 の4パターンで視認性を確認可能。
  - 保存したスタンプ一覧はタップでのワンタッチプレビュー切替および**タッチ＆ドラッグ並び替え**に対応。

---

### **Step 4: メイン・タブ画像作成 (Main & Tab Icons Generation)**
- **Step 4進入時のAI自動生成**:
  - `gemini-3.1-flash-lite-image` を活用し、メイン画像およびトークルームタブ画像を全自動生成。
- **公式規格画像フォーマット**:
  - **メイン画像**: 横240px × 縦240px（上下左右10pxの公式余白自動確保）。
  - **トークルームタブ画像**: 横96px × 縦74px（表情部分をクローズアップ配置）。
- **個別プロンプト修正 ＆ 再生成**:
  - メイン・タブ画像それぞれに対して修正指示を入力し、個別に再生成が可能。

---

### **Step 5: 保存 ＆ PDF印刷フォーマット (Export & PDF Print Engine)**
- **公式 `OC_LINEスタンプ印刷フォーマット.pdf` ベクター連携**:
  - 名古屋芸術大学オープンキャンパス公式のA4印刷テンプレートPDFへ生成画像をダイレクトに合成。
- **高精度PDF生成エンジン (`pdfGenerator.ts`)**:
  - **クロマキー自動透過＆並び替え連携**: 画像の背景（#FF00FF）を自動透明化し、ドラッグ＆ドロップで並び替えた順番通りにPDFへ配置。
  - **幾何学中心配置**: メイン画像・手描き線画・QRコード（ダウンロード用）を左カラムへ最適オフセット配置。
  - **8点スタンプバリエーション配置**: 右側大型エリアを2列×4行に等割したグリッドへ均等ど真ん中配置。
- **アプリ組み込み高精細PDFビューア (`<iframe>`)**:
  - アプリ内でレイアウト崩れのない完璧な印刷プレビューを確認。
- **出力操作**:
  - **「PDFを再生成」**: 最新の生成画像群でPDFを即座に再レンダリング。
  - **「PDFをダウンロード」**: 公式規格のA4 PDFファイルとしてローカル保存。
  - **「印刷する (PDF直接印刷)」**: ブラウザのPDFドライバー経由でズレなくA4印刷。
- **アプリ組み込み高精細PDFビューア (`<iframe>`)**:

## 💻 ローカル開発環境の起動方法

1. **リポジトリのクローン・依存パッケージのインストール**:
   ```bash
   npm install
   ```

2. **環境変数の設定 (`.env.local`)**:
   プロジェクトルートに `.env.local` ファイルを作成し、Gemini API キーを設定します:
   ```env
   VITE_GEMINI_API_KEY=your_gemini_api_key_here
   ```

3. **開発サーバーの起動**:
   ```bash
   npm run dev
   ```
   ブラウザで `http://localhost:5173` にアクセスして操作します。
