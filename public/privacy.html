プライバシーポリシー

アプリケーション名: 手描きでスタンプメーカー ／ 最終更新日: 2026年8月29日

1. サービス概要

「手描きでスタンプメーカー」（以下「本サービス」）は、手描きの線画から AI（Google Gemini API）を活用して LINE スタンプ画像を自動生成する Web アプリケーションです。

本サービスは名古屋芸術大学（nua.ac.jp ドメイン）に所属するユーザーを対象としています。

2. 収集する情報

2.1 Google アカウント情報（OAuth 認証を通じて取得）

情報の種類 OAuth スコープ 取得の目的
メールアドレス email ユーザーの識別、nua.ac.jp ドメインの所属確認
表示名 profile（openid） アプリ内でのユーザー名表示
プロフィール画像 URL profile（openid） アプリ内でのアバター表示（任意）

上記以外の Google アカウント情報（連絡先、カレンダー、Google ドライブ等）には一切アクセスしません。

2.2 ユーザーが作成するデータ

データの種類 説明
線画データ ユーザーが描画またはアップロードした画像
AI 生成画像 AI が生成したスタンプ・メイン画像・タブ画像
プロジェクト設定 スタイル選択、プロンプトテキスト、ステップ状態等

2.3 自動的に収集される情報

  • ログイン日時（最終アクセス日の記録のため）
  • 認証セッション情報（Supabase Auth による自動管理）

行動トラッキング、アクセス解析、広告用の情報収集は一切行いません。

3. データの利用目的

本サービスが収集するデータは、以下の目的のみに使用します。

利用目的 対象データ 詳細
利用可能ユーザーの識別 メールアドレス 本サービスは nua.ac.jp ドメインのメールアドレスを持つユーザーのみが利用できます。ログイン時にメールアドレスのドメインを確認し、利用資格を判定します。
生成画像とユーザーの紐づけ ユーザー ID、プロジェクト・画像データ ユーザーが作成した線画・AI 生成画像をデータベース上でユーザーアカウントと紐づけ、プロジェクトの保存・復元を可能にします。
AI 画像生成 線画データ、プロンプトテキスト Google Gemini API に線画とプロンプトを送信し、スタンプ画像を生成します。送信データは画像生成処理のみに使用されます。
ユーザー体験の向上 表示名、プロフィール画像 アプリ内にユーザー名とアバターを表示し、パーソナライズされた体験を提供します。

収集した個人情報を、広告、マーケティング、プロファイリング、第三者への販売・貸与・共有の目的で使用することはありません。

4. データの保管と削除

4.1 保管場所

すべてのユーザーデータは Supabase（クラウドデータベースサービス）上に保管されます。通信は全経路で TLS 1.2 以上により暗号化されています。

4.2 データの自動削除

重要: 30日間の自動削除ルール

最終アクセス日から 30日間 ログインがない場合、そのユーザーに関連するすべてのデータが自動的に削除されます。

  • プロジェクトデータ（線画・生成画像・設定）
  • ログイン履歴・認証セッション情報
  • アカウント情報

削除されたデータを復元することはできません。継続利用される場合は、30日以内に一度ログインしてください。

4.3 ユーザーによる手動削除

  • アプリ内の操作で、個別のプロジェクトや画像をいつでも削除できます。
  • アカウント全体の即時削除を希望される場合は、下記の連絡窓口までご連絡ください。

5. データの第三者提供

提供先 提供するデータ 目的
Google（Gemini API） 線画データ、プロンプトテキスト AI による画像生成処理（生成のみ。Google 側の利用規約に準拠）
Google（OAuth 認証） 認証トークン ログイン認証の検証
Supabase 全ユーザーデータ データベースホスティング（データ処理委託先）

上記以外の第三者にユーザーデータを提供することはありません。法令に基づく開示請求があった場合を除きます。

6. Cookie とローカルストレージ

種類 用途 トラッキング
認証 Cookie / localStorage Supabase Auth によるセッション管理 なし
localStorage（current_project_id） 最後に開いていたプロジェクトの記憶 なし

広告・トラッキング目的の Cookie は使用しません。

7. セキュリティ対策

  • データベースのアクセスは Row Level Security（RLS） により、認証済みユーザー自身のデータのみに制限されます。
  • すべての通信は HTTPS（TLS 1.2 以上）で暗号化されます。
  • Google OAuth 2.0 の PKCE フローを採用し、認証コードの傍受を防止します。
  • API キーやシークレットはサーバー側の環境変数で管理し、クライアントコードに露出しません。

8. ユーザーの権利

ユーザーは以下の権利を有します。

  • アクセス権: ご自身のデータがどのように保管されているかを確認する権利
  • 削除権: ご自身のデータの削除を要求する権利
  • 異議申立権: データの取扱いについて異議を申し立てる権利
  • 同意撤回権: Google アカウントの連携をいつでも解除する権利（Google アカウント設定の「サードパーティのアプリとサービス」から解除可能）

9. 対象ユーザーの範囲

本サービスは、名古屋芸術大学（nua.ac.jp）ドメインの Google アカウントを保有するユーザーのみが利用できます。

nua.ac.jp 以外のメールアドレスでログインを試みた場合、サービスへのアクセスは拒否されます。

10. ポリシーの変更

本ポリシーは、サービスの変更や法令の改正に応じて更新される場合があります。重要な変更があった場合は、アプリ内で通知します。
